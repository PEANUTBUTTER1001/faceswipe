# Faceswipe

얼굴 제스처로 화면을 조작하는 Android 접근성 앱

전면 카메라로 고개 움직임과 입 벌림을 인식해 지정된 앱에서 스와이프, 탭 등의 동작을 손 대지 않고 실행됩니다.


## 🗂️ 프로젝트 개요

- **앱 이름** : Faceswipe
- **구성원** : 1인 개발
- **작업 기간** : 2026.06 ~ 작업중(배포 준비 중)
- **플랫폼** : Android
- **개발 언어** : Kotlin
- **개발 환경** : Android Studio
- **외부API 및 서비스** : On-device AI Google ML Kit API

## 🎯 서비스 목표

손 사용이 불편한 사용자가 특정 반복 동작을 얼굴 움직임만으로 수행하기 위한 앱입니다.

## ✨ 서비스 주요 기능

- 전면 카메라 기반 실시간 얼굴 인식 (CameraX + ML Kit Face Detection, 기기 안에서 처리)
- 3가지 제스처 트리거 감지: 고개 왼쪽, 고개 오른쪽, 입 벌림 (윙크는 오인식이 잦아 제거)
- 3가지 실행 동작: 위로 스와이프, 아래로 스와이프, 하단 1/4 영역 탭
- 앱별 제스처-동작 매핑 (DataStore 영속 저장, 처음 설치 시 기본값 제공)
- 첫 실행 소개와 설정 마법사: 접근성 고지·동의 → 카메라 → 알림 권한을 단계별 안내
- 제스처 인식 알림: 인식할 때마다 화면 위에 "제스처 → 동작"을 잠깐 표시 (설정에서 끌 수 있음)
- 빠른 설정 타일로 앱을 열지 않고 켜기/끄기
- 대상 앱이 화면에 있을 때만 카메라를 켜는 절전 동작
- 포그라운드 서비스와 실행 중 알림(대상 앱 상태, 카메라 사용 불가 안내, 중지 버튼)

## 📖 사용법

### 1. 첫 실행과 권한 설정

첫 실행 시 소개 화면에서 "시작하기"를 누르면 설정 마법사가 차례로 안내합니다.

1. **접근성 고지·동의**: 접근하는 정보, 사용 방법, 공유 여부, 하지 않는 일을 확인한 뒤 "동의하고 설정 열기"
   → 시스템 설정 > 접근성 > 설치된 앱 > faceswipe 제스처 서비스를 켭니다.
   앱으로 돌아오면 상태를 다시 확인해 다음 단계로 넘어갑니다.
2. **카메라 권한**: 설명을 본 뒤 허용합니다. 다시 묻지 않음 상태라면 앱 정보 화면으로 안내합니다.
3. **알림 권한** (Android 13 이상): 실행 중 알림의 중지 버튼을 보려면 허용합니다. 건너뛰어도 동작합니다.

마법사를 건너뛰어도 홈의 [권한] 항목이나 비활성 실행 스위치를 누르면 부족한 단계부터 다시 안내합니다.

### 2. 제스처 매핑 설정

홈 > 앱별 제스처 설정에서 대상 앱(유튜브 / 밀리의 서재)별로 각 제스처에 연결할 동작을 고릅니다.
변경은 즉시 저장되고 실행 중인 서비스에도 바로 반영됩니다. "연결 모두 해제" 직후에는 실행 취소할 수 있습니다.

처음 설치했을 때의 기본값 (모든 대상 앱 공통):

| 제스처 | 기본 동작 |
|---|---|
| 고개 오른쪽 돌리기 | 위로 스와이프 |
| 고개 왼쪽 돌리기 | 아래로 스와이프 |
| 입 벌리기 | 선택 안 함 |

### 3. 실행

- 홈의 "faceswipe 실행" 스위치 또는 빠른 설정의 faceswipe 타일로 켜고 끕니다.
- 대상 앱을 열면 카메라가 켜지고(Android 12 이상은 상태 표시줄에 카메라 사용 표시) 얼굴 제스처를 인식합니다.
  대상 앱이 아닌 화면에서는 카메라가 꺼진 채 대기합니다.
- 다른 앱이 카메라를 쓰고 있으면 홈과 알림에 "카메라를 쓸 수 없어요"를 표시합니다.
- 중지하려면 스위치·타일·알림의 "중지"를 누르거나 최근 앱 목록에서 앱을 제거합니다.
- 시스템이 메모리 부족으로 앱을 종료하면 자동으로 다시 켜지지 않습니다. 다시 켜 주세요.

홈 > 사용 방법에서 제스처별 동작법과 잘 인식되는 자세를 확인할 수 있습니다.

## 👆 제스처와 동작

| 제스처 트리거            | 설명                         |
|--------------------|----------------------------|
| 고개 왼쪽 (HeadLeft)   | 고개를 왼쪽으로 돌렸다가 정면으로 복귀      |
| 고개 오른쪽 (HeadRight) | 고개를 오른쪽으로 돌렸다가 정면으로 복귀     |
| 입 벌림 (MouthOpen)   | 입을 크게 벌린 채 잠깐 멈췄다가 다물기     |

| 실행 동작                   | 설명             |
|-------------------------|----------------|
| 위로 스와이프 (SwipeVertical) | 화면 아래에서 위로 스와이프 |
| 아래로 스와이프 (SwipeVertical) | 화면 위에서 아래로 스와이프 |
| 탭 (Tap)                 | 화면 하단 1/4 영역 탭 |

입 벌림에는 짧은 움직임과 구분하기 위한 최소 유지 시간과 임계값이 적용됩니다
(`GestureConfig`). 말하는 중에는 입 벌림이 잘못 인식될 수 있습니다.
얼굴이 0.5초 이상 보이지 않거나 대상 앱을 벗어나면 진행 중이던 제스처 상태를 초기화합니다.

## 🏗️ 프로젝트 아키텍쳐

Now in Android(NiA) 아키텍처를 참고한 멀티모듈 구성입니다.

```
faceswipe/
├── app/                  앱 진입점, MainActivity(첫 실행 분기), 네비게이션 그래프
├── feature/faceswipe/    화면(Compose): 소개, 설정 마법사, 홈, 제스처 설정, 사용 방법
├── domain/faceswipe/     UseCase, 제스처 감지기, 도메인 모델(기본 매핑 포함), 인터페이스
├── data/faceswipe/       Repository 구현, 포그라운드·접근성·타일 서비스, 오버레이, DataStore
├── core/ui/              공통 테마(고정 팔레트) 및 설정 목록 컴포넌트
├── build-logic/          Convention Plugin (공통 빌드 설정)
└── docs/                 디자인 지침 (android-settings.md)
```

레이어 의존 방향은 app → feature → domain 이며, data가 domain의 인터페이스를 구현하는 의존 역전 구조입니다.

## 🔐 필요 권한

| 권한                                                 | 용도                                          |
|----------------------------------------------------|---------------------------------------------|
| `CAMERA`                                           | 전면 카메라로 얼굴 인식 (설정 마법사에서 요청)                 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_CAMERA` | 대상 앱 사용 중 카메라 유지                            |
| `POST_NOTIFICATIONS`                               | 실행 중 알림과 중지 버튼 (Android 13+, 설정 마법사에서 요청)   |
| 접근성 서비스                                            | 대상 앱 감지, 제스처 실행, 인식 알림 표시 (고지·동의 후 사용자가 직접 켬) |
| `INTERNET` / `ACCESS_NETWORK_STATE`                | 앱 기능에는 사용하지 않음. ML Kit 라이브러리가 진단 통계 전송에 사용   |

## 🧪 테스트

```bash
./gradlew test
```

## 🚀 출시 빌드

release 빌드는 R8 축소·난독화와 리소스 축소를 사용합니다. 서명 정보는 환경변수로만 주입합니다.

| 환경변수 | 내용 |
|---|---|
| `FACESWIPE_KEYSTORE_FILE` | 업로드 키스토어 파일 경로 |
| `FACESWIPE_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `FACESWIPE_KEY_ALIAS` | 키 별칭 |
| `FACESWIPE_KEY_PASSWORD` | 키 비밀번호 |

4개가 모두 있을 때만 서명하고, 없으면 서명되지 않은 release를 만듭니다.
GitHub Actions(`cd.yml`)는 Secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`를 사용하며,
하나라도 없으면 빌드를 실패시킵니다.
